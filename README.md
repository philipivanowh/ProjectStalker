# ProjectStalker

This project includes a bash script to:
- Put a Wi-Fi adapter into monitor mode
- Scan nearby Wi-Fi networks
- Capture WPA handshakes
- Perform password cracking using a wordlist

!!! For educational use only. Do **not** use on networks without explicit permission.

## Script: wifi_attack.sh

Run this script on a Linux system with `aircrack-ng` installed and a USB Wi-Fi adapter that supports monitor mode.
